# Claude implementation prompt for MovBugios

Work in the MovBugios repository as a senior React Native Expo and AVPlayer engineer. Inspect the installed Expo player package and its native AVPlayer bridge, API interceptors, SecureStore integration, Firebase endpoint resolution, and navigation lifecycle. Keep the existing playback/UI contracts. Use loopback fixtures.

1. Generate one UUID per intentional play and carry it as `X-Playback-Attempt-Id` for Kidoo control requests. Pass it to same-origin native manifest requests only where the installed native API can scope headers per destination. If AVPlayer header interception cannot guarantee this, correlate JS control requests and report missing native correlation explicitly. Never attach Kidoo authorization, cookies, or diagnostic headers to CDN domains or redirected destinations.
2. Keep one owner for the native player and its item. Coalesce duplicate initialization from React rerenders, navigation focus, and AppState events. Abort pending fetches when switching tracks or unmounting. Replace or release the old native item/player according to the actual Expo package contract and remove time observers and listeners. Apply a local generation check before attaching async results. Preserve intentional PiP or background audio through the existing native lifecycle owner.
3. Choose the supported Kidoo playback resolver already used by the app. Avoid invoking both raw playlist and HLS resolver for a single intent. Keep only documented heartbeat behavior, with one cancellable scheduler for the active attempt and no competing foreground/background timers.
4. Treat Kidoo API JWT refresh and provider playback authorization independently. Use one refresh promise per account and atomically store the replacement pair using existing SecureStore primitives. Replay eligible requests once. Honor delta-seconds and HTTP-date `Retry-After` on `429` and overload `503`. Stop automatic playback retries on `MIRROR_SESSION_REVOKED` or an upstream challenge. For an expired variant, perform at most one authorized master reload for the current attempt with cancellation and cooldown respected.
5. Bind active manifests and relative variant URLs to the issuing Kidoo origin. Apply a trusted Firebase-discovered URL change to new operations and avoid restarting an otherwise working AVPlayer just because the base URL changes. Never send credentials until the destination and redirect policy have been verified.
6. Add Jest lifecycle tests and an iOS simulator or native fixture for rapid taps, unmount while resolving, AVPlayer release, PiP/background transitions, Retry-After, revocation, expired variants, rotating login refresh, and Firebase endpoint changes. Record sanitized operation, latency and outcome per UUID. Exclude raw URLs, query strings, headers, and credentials from diagnostics.
